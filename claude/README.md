# Momentic for Claude

Run Mo bug bashes and review findings with the bundled `mo-qa` skill. The plugin
connects to the hosted MCP server at https://mcp.momentic.ai using Momentic
OAuth. You need a Momentic account to sign in.

The plugin sends your prompts, targets, and briefs to Momentic's hosted MCP
server only. It includes no local servers, hooks, or scripts. Localhost and
private targets need the `qa` CLI; follow the skill's instructions for those
targets.

See the [connector guide](https://momentic.ai/docs/mo/chatgpt-and-claude) and
[privacy policy](https://momentic.ai/legal/privacy). For support, contact
support@momentic.ai.
